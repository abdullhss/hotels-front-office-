PROCEDURES & TABLES USED BY THE HOTELS FRONT-OFFICE APP
=====================================================
Purpose: list of every stored procedure and table the frontend calls, so the
backend team can grant this app's DataToken ("Hotels") / users access to them.

NOTE: names are sent AES-encrypted (same scheme as the archive project). The
plaintext names exist only server-side, so each entry gives the ENCRYPTED value
exactly as sent, plus the constant name / file / columns to help identify it.
Decrypt server-side to get the real procedure / table name.

Backend base URL : see public/config.json ("url"); DataToken: "Hotels"

--------------------------------------------------------------------------------
0) ENDPOINTS USED
--------------------------------------------------------------------------------
Checklogin                 login (ProcedureName sent as "" ; ParametersValue = Email#Pass#DeviceSerial#1#$????)
RefreshToken               JWT refresh
ExecuteProcedureManager    all stored procedures in section 1
DoTransactionManager       add / edit / delete rows on tables in section 2
DoMultiTransactionManager  multi-table add (reservation + units, unit assignment + persons)
UploadFileEnc / UploadFileWebSite / DownloadFileEnc   file upload / delete / download
